# 📸 Responsive Photo Gallery

## 📌 Overview

The **Responsive Photo Gallery** is a simple and elegant web project that displays images in a responsive grid layout. The gallery automatically adjusts to different screen sizes, providing a smooth viewing experience across desktops, tablets, and mobile devices.

This project demonstrates the use of modern **HTML and CSS techniques for responsive web design**.

---

## 🚀 Features

* 📱 Fully responsive layout
* 🖼️ Image grid gallery
* ⚡ Fast loading images
* 🎨 Clean and modern UI
* 💻 Works on desktop, tablet, and mobile devices

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (optional)
